# zexokky | aka hexokryn

Минималистичный чёрно-белый сайт. Статические HTML, CSS и JavaScript, без внешних шрифтов и зависимостей браузера.

## Запуск

```sh
python3 -m http.server 3000
```

Данные автора — `content.json`, оформление — `styles.css`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает только публичные файлы в `_site` и публикует их через GitHub Pages. В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**, если Pages ещё не включён. После push в `main` публикация запускается автоматически; её также можно запустить через **Actions → Publish website → Run workflow**.

## Telegram

GitHub Pages не запускает серверный Python. Вместо этого GitHub Actions получает публичные сообщения `https://t.me/s/zexokkydev` и сохраняет их в `feed.json` перед публикацией. Обновление запланировано дважды в час (GitHub может задерживать запуск), также выполняется при push и ручном запуске workflow. Токен Telegram не нужен. Посты отображаются текстом; медиа открываются по ссылке на оригинал.

При ошибке Telegram сохраняется предыдущий файл; сайт остаётся доступен. Если записей ещё нет, отображается ссылка на канал. После восстановления доступа следующий workflow заполнит ленту. Успешное обновление сохраняется bot-коммитом в `main`; защита ветки может препятствовать сохранению, но не публикации текущей ленты. Расписание GitHub Actions в неактивном публичном репозитории может отключиться через 60 дней.

Обновить ленту вручную (Python 3.11+, HTTPS-доступ к `t.me`):

```sh
python3 scripts/update_feed.py
```

## Проверки

```sh
python3 -m unittest discover -s tests -v
node --check app.js
python3 scripts/build.py
```

Тесты используют локальный пример разметки канала и не подтверждают доступность живого Telegram. Сборка не включает Python-скрипты, тесты и Git-метаданные в опубликованные файлы.
